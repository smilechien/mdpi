# BibliometricMDPI

 
| `openalex_author_mode.R` | OpenAlex author lookup and first/last-author data preparation. |
| `openalex_dendrogram.R` | Mode 5 strongest-link FLCA dendrogram renderer. |
| `openalex_flca_ms_sil_module.R` | FLCA module copied from `jmirscopus` for Mode 5 parity. |

**OpenAlex author mode.** This is a separate author search, not the local metadata Author FLCA. Search matches retain OpenAlex relevance order; the selected OpenAlex ID, institution, h-index, and profile link are visible so identical names can be distinguished. Each work contributes its first and last OpenAlex author IDs; these form the weighted coauthorship network. Mode 5 uses the same FLCA module as `jmirscopus` and selects up to 20 nodes from the 100 most frequent candidates. The network shows their shared-work links. The strongest-link dendrogram uses those same selected nodes and one strongest leader link per follower; distance is 1 minus normalized WCD, and unlinked nodes join at distance 2. Its labels include first/last-author work counts and highlight the highest-count leader in red. The Kano plot places the sum of displayed link weights on the horizontal axis, first/last-author work count on the vertical axis, and SHC (1 − Burt constraint) in bubble size. The cards report AAC from the top three selected role-work counts, focal SHC, CLI = last/first works, OpenAlex profile h-index, MAR = (n − n*)/n, OpenAlex work count n, and n* = retrieved works where the focal author is first or last. AAC, CLI, and MAR are unavailable when the profile exceeds the 10,000-work fetch limit; n* is then a lower bound. These are descriptive bibliometric measures, not Kano survey responses.
